***REMOVED*** Бюджеты ЦФО — дашборд исполнения бюджетов

Веб-приложение для контроля исполнения годовых бюджетов центров финансовой
ответственности (дирекций): сколько выделено, сколько израсходовано, сколько
уже заявлено к оплате и сколько лимита осталось свободным.

Заменяет ручную работу в Excel: план приходит из файлов дирекций, факт — из
выгрузки 1С, обязательства заводятся в интерфейсе, а расчёт остатков,
контроль лимитов и журнал изменений ведёт система.

> Репозиторий содержит только код. Рабочие данные (суммы бюджетов, контрагенты,
> договоры) в него не попадают — см. `.gitignore`. Данные в макете обезличены.

***REMOVED******REMOVED*** Возможности

| Раздел | Что делает |
|---|---|
| **Дашборд** | карточки ЦФО с батарейкой освоения, статусом и свободным лимитом |
| **Сводка** | таблица по всем ЦФО: план / факт / заявки / остаток, фильтр по риску |
| **Карточка ЦФО** | строки бюджета по месяцам, привязанные платежи, добавление и удаление строк |
| **Заявки** | обязательства с проверкой свободного лимита (предупреждает, но не блокирует) |
| **Сопоставление** | привязка неразобранных платежей 1С к строкам бюджета, автосопоставление |
| **Тепловая карта** | отклонение факта от плана по месяцам, только закрытые периоды |
| **Корректировки** | перенос лимита между месяцами строки и между строками ЦФО + журнал |
| **Импорт / экспорт** | загрузка Excel с сопоставлением колонок, выгрузка в формат «Оперплан ЦФО» |

***REMOVED******REMOVED*** Как считается

Формулы повторяют лист «Оперплан ЦФО» рабочего файла ликвидности:

```
Итого опер план  = Факт + неоплаченные заявки
Остаток бюджета  = БЮДЖЕТ − Факт                 (остаток по кассе)
Свободный лимит  = БЮДЖЕТ − Итого опер план      (колонка «Бюджет - опер план»)
```

Дополнительно:

- **Все суммы с НДС**, в рублях. В интерфейсе округляются до рублей, в Excel выгружаются с копейками.
- **Неиспользованный остаток месяца** переносится на следующий месяц внутри той же
  строки бюджета (флаг `carryover`); в конце года остаток обнуляется.
- **Отчётная дата** и «факт закрыт по месяц» задаются в шапке: от них считается
  ожидаемый темп освоения, с которым сравнивается фактический.
- **Статусы**: `перерасход` (факт > бюджета) → `заявки сверх лимита` (свободный лимит < 0)
  → `опережает темп` (освоение выше ожидаемого на 15 п.п.) → `в графике`.

***REMOVED******REMOVED******REMOVED*** Первичная загрузка года

Из листа «Оперплан ЦФО» файла ликвидности — одной командой:

```bash
python scripts/seed_operplan.py "<путь к файлу.xlsx>" 2026
```

Скрипт разложит данные по строкам бюджета, создаст платежи за закрытые месяцы
и заявки на будущие, а также выставит границу закрытого периода.

Дальше данные обновляются через интерфейс на вкладке «Импорт / экспорт»:
план от дирекций, выгрузка факта из 1С, оперплан целиком.

***REMOVED******REMOVED******REMOVED*** Проверка парсера на рабочем файле

```bash
python scripts/check_real_file.py "<путь к файлу.xlsx>"
```

Печатает найденные колонки, границу факта, блоки и расхождения сумм — удобно
при изменении раскладки исходного файла.

***REMOVED******REMOVED*** Роли и доступ

- **Финансовый отдел** — видит все ЦФО, меняет настройки периода, сопоставляет платежи, загружает файлы.
- **Руководитель ЦФО** — видит только свои ЦФО, добавляет строки, заявки и признак «вне бюджета».

Способ входа определяет ИТ-отдел (планируется доменная учётная запись). До этого
приложение работает в доверенной сети: пользователь берётся из заголовка `X-User`,
по умолчанию — финансовый отдел. Пароли в приложении не хранятся и не проверяются;
когда появится AD, достаточно заменить `current_user` в `app/auth.py`.
